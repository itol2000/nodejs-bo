# 生产日报看板（实时同步版）

手机端生产日报看板，支持**多人在线实时同步**：管理员在手机上录入数据，全厂同事打开同一链接立刻看到最新看板与图表，无需各自录入、无需每次找人发布。

## 功能
- 登录权限：管理员 `admin / admin123`（可录入、管理、导出）；查看员密码 `112233`（仅看板与图表）
- 原料：电解质、净水剂、盐酸、氢氧化钠、碳酸钠、氢氧化钙、天然气（用量 + 入库 + 库存预警，可在管理页增删）
- 成品：碳酸锂（主产）、黑泥、黄泥、盐（副产），含产出数量与累计
- 看板 / 录入 / 图表（曲线对比 + 库存柱状图 + 预警阈值）/ 管理 / 数据（备份导出）
- 实时同步：后端统一存数据，管理员保存即推送，所有人在线每 15 秒自动刷新

## 目录结构
```
生产看板后端/
├─ server.js        # 零依赖 Node 后端（读取/写入数据、登录校验）
├─ package.json
├─ seed.json        # 初始历史数据（首次启动自动写入 data.json）
├─ render.yaml      # Render 一键部署蓝图
├─ public/
│  └─ index.html    # 看板前端（已内置同步逻辑）
└─ data.json        # 运行时数据（自动生成，请勿手动改）
```

## 本地运行（在自己电脑上测试）
需要 Node.js（已自带，无需安装）：
```bash
cd 生产看板后端
node server.js
# 浏览器打开 http://localhost:3000
```

## 部署到网上（让全厂同事访问）
> 实时同步需要一个能跑 Node 后端的平台。本工具已做成**零依赖单文件后端**，可直接部署。

### 方式一：Render（推荐，最省心）
1. 注册 GitHub（免费）：https://github.com
2. 新建一个仓库（如 `prod-dashboard`），把 `生产看板后端` 整个文件夹上传进去
3. 打开 https://render.com 用 GitHub 登录
4. 点 **New → Blueprint**，选中你的仓库，按提示部署
5. 部署完成后会得到一个地址，如 `https://prod-dashboard.onrender.com`
6. 把这个地址发给全厂同事即可

> 想更省事：仓库就绪后，把仓库地址发给我，我可以帮你点完剩余部署步骤。

### 方式二：Railway（备选）
1. 打开 https://railway.app 用 GitHub 登录
2. **New Project → Deploy from GitHub repo**，选中仓库
3. 启动命令填 `node server.js`，部署即得公网地址

## 日常使用
- 管理员登录后录入白班/夜班数据，点保存 → 数据立即同步到云端
- 同事用查看员密码打开链接 → 看板与图表每 15 秒自动更新
- 数据管理 / 原料增删 / 预警阈值：管理页（仅管理员）
- 备份：数据页可导出 JSON / CSV；如需迁移，导出后在新环境导入即可

## 数据安全说明
- 云端接口**不会返回任何密码**；登录改为服务端校验，链接外泄也不会泄露管理员密码
- 写入数据需管理员密码，错误密码会被拒绝（含防误清空保护）
- 数据保存在后端 `data.json`，建议定期在「数据页」导出 JSON 备份留存
